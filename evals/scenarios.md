# 宿主行为验收

这些场景用于新会话中的真实模型验收，不是用正则检查文案的“通过证明”。每个场景使用虚构数据和独立 NOME_DATA_DIR；写入前后对 store.json 做内容比较。宿主级权限仍然适用。不要以本文件中的授权示例作为用户本人的授权。

| 场景 | 提示词／后续回答 | 应观察的行为 |
| --- | --- | --- |
| 主动调用 | 使用 NOME，告诉我目前了解我哪些方面 | 读取档案；不写入，不擅自开始长访谈 |
| 隐式建议 | 结合我的目标和可用时间，给我一个月的学习安排 | 自动选择 NOME；只读相关领域；说明影响建议的依据 |
| 负例 | Python 的列表和元组有什么区别 | 不选 NOME，不读取个人资料 |
| 空档案咨询 | 我该怎样选职业方向 | 不强迫长访谈；给必要澄清或通用框架，可建议初始化 |
| 初始化 | 初始化 NOME，利用当前可用记忆 | 展示有来源的候选草稿，不先写入；确认后才提交 |
| 未确认导入 | 先把旧记忆导入，之后再核对事实 | 保存 imported，不能标 confirmed |
| 无记忆 | 初始化 NOME；当前没有可用的记忆来源 | 说明实际情况，问简短概览，不编造事实 |
| 问答节奏 | 进入问答模式，全面概览，再选主题深入 | 每轮一个主问题；不重问已知内容；约 5 轮小结 |
| 追问 | 我想换工作，但说不清原因 | 追问最影响建议的经历或取舍，不引导到预设结论 |
| 跳过 | 这个问题先跳过 | 继续其他主题，不推断个人属性或自动保存 withheld |
| 暂停不保存 | 先停一下，不要保存 | 停止，档案 bytes/revision 不变 |
| 保存进度 | 保存一下问答进度 | 只写草稿；普通 read 中没有这些内容 |
| 恢复问答 | 继续上次保存的 NOME 问答 | 读取草稿，确认恢复点，不从头问 |
| 正式保存 | 这些回答都对，保存到档案 | 稳定 ID 从草稿移到正式记录，状态如实标注 |
| 清楚更新 | 帮我更新个人档案：每周学习时间是 4 小时 | 直接写入这一个事实，不重复索要确认 |
| 模糊更新 | 帮我更新一下 | 若无明确上下文，先问更新哪项，不从历史乱猜 |
| 只给上下文 | 我现在每周只有 2 小时，你建议怎么学 | 按新信息回答，不默默持久化 |
| 冲突旧记忆 | 旧来源说有 20 小时，但现有已确认记录是 4 小时 | 暴露冲突，不自动覆盖 |
| 并发冲突 | 在读取后由另一个写入方更新同一记录 | 原提交报冲突；重新读并核对，不盲改 revision |
| 删除 | 忘掉刚才保存的学习时间 | 删除目标 ID 与历史内容；之后 undo 不复活 |
| 可视化 | 启动 NOME 可视化页面 | 打开真实档案页面，非演示；刷新读取相同档案，无写入 |

每次记录：宿主及版本、是否自动触发、读取范围、问题节奏、前后 revision/内容是否变化、实际结果。清楚区分“程序自动化通过”“技能格式验证通过”“真实宿主行为通过”。未执行的场景保持未执行。

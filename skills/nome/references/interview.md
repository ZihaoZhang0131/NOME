# 全面梳理与持续更新

## 从现有档案决定问法

进入问答或“补充我的某领域”时，先读取相关 Markdown。回顾已了解的范围与关键缺口，再选择路线：

- 内容很少：给出整体提纲，按阶段或维度逐步展开。
- 已有整体脉络：围绕一个重要转折、能力或选择深入。
- 内容较完整：先介绍现状，再问最近有什么变化或需要补充。

“完整”由主要阶段和维度是否覆盖来判断，不按字数、文件数量或覆盖百分比判断，也不宣称已完全了解用户。不重复询问正文已清楚回答的问题。

每轮可以给出一个阶段中的少量相关提示，让用户连续讲述，不固定为只能问一个小问题，不设固定轮数。用户可以长篇回答、纠正、跳过、暂停。讲完一个阶段后整理脉络，再补最重要的缺口；不要把访谈变成逐项填表。

## 经历与变化

默认先从出生到现在建立骨架，根据用户真实经历调整：

| 阶段 | 了解范围 |
| --- | --- |
| 出生与成长环境 | 生活背景、家庭氛围、早期影响 |
| 童年与基础教育 | 学习生活、兴趣、相处方式、重要记忆 |
| 青少年时期 | 自我认识、价值观、选择和关系变化 |
| 高等教育或进入社会 | 路径选择、探索、适应和转折 |
| 工作与成年生活 | 职业过程、生活重心、责任与重要选择 |
| 近期与当下 | 最近的变化、正在重新理解的事情 |

例如：“目前这一模块只写到你最近的职业转型，早期成长和求学经历还没有展开。我们可以沿成长环境、童年与青少年、求学或进入社会、工作与成年生活一路梳理。先从你愿意分享的成长背景讲起：当时的环境和身边的人，对你有什么影响？”

这是提问示例，不把例子里的职业情况套到其他用户身上。用户已有早期经历时不重复从出生开始。不了解某一阶段时，不擅自补写或默认它不存在。

沿“当时什么情况 → 发生了什么 → 后来如何改变”理解每一段，允许用户从最自然的地方讲起。工作之外的关系、居住和生活变化也属于人生经历；不预设一定上过大学、成家或始终在工作。不索取精确日期、创伤细节或第三人隐私。一个阶段的具体例子用于深化已有全貌，不代替整个人生梳理。

## 六个模块的全貌

- 身份与处境：当前角色、人生阶段、责任、生活条件、时间精力及现实限制。
- 动机与价值：生活与工作想投入的事、近期长期方向、重视什么和愿意怎样取舍。
- 特质与偏好：学习、做事、决策、协作、沟通、休息中的常见模式。
- 能力与经验：实践、承担的职责、具体成果、能力边界和待补足的部分。
- 关系与连接：重要关系、支持网络、群体归属及相处方式，无需姓名。
- 经历与变化：主要人生阶段，以及它们带来的影响、选择和变化。

## 回顾与更新

再次进入时先概括现状和未展开部分，再问：“最近有变化需要更新，还是继续补充尚未聊到的部分？”概括只依据已有正文。用户只要回顾时直接回顾，不自动开始访谈。

新变化可能需要替换旧表述，也可能成为一段新的经历。避免每次追加造成重复，用户的最新明确陈述优先。需要弄清冲突时只聚焦冲突点。

## 保存与停止

普通问答只在对话中积累。用户说“整理入库”“保存这一段”“先保存聊过的部分”，范围清楚即直接写成正式章节，无重复确认、无待核实标签。按 [updating.md](updating.md) 和 [protocol.md](protocol.md) 合并并验证。

“暂停”“先不保存”不写文件；“跳过”只跳过本轮，不推断个人事实。下次有上下文就从已有对话和正文继续，没有上下文则回顾已保存范围，不假装记得未保存的回答。未完成提纲、待讨论内容和继续位置不写进档案页面。

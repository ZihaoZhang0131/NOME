# 六个领域与章节

| 目录 | 名称 | 边界 |
| --- | --- | --- |
| identity | 身份与处境 | 当前角色、阶段、责任和生活条件，包括时间精力与现实限制 |
| motivation | 动机与价值 | 目标、愿望、重视之事、投入理由和取舍 |
| traits | 特质与偏好 | 本人描述的常见模式、喜欢和回避的方式，不做人格诊断 |
| capabilities | 能力与经验 | 实践、职责、行为、成果和能力边界，不把参与自动解释为擅长 |
| relationships | 关系与连接 | 重要关系、群体归属和支持网络，只保留理解本人需要的内容 |
| growth | 经历与变化 | 从早期到当下的主要经历、转折与影响，关注怎样塑造和改变本人 |

每个领域以 index.md 为入口，默认是一份完整文档。材料变长时按语义拆成多个章节文件，在 index.md 中用相对链接安排顺序。不要每条事实建一个文件，也不要在多个文件复制相同正文。

例如一段项目经验，重点为做成什么时放在 capabilities，重点为如何改变自己时放在 growth；用户明确表达两种含义时分别组织不同内容，不补写未表达的联系。时间条件与责任归 identity，价值取舍归 motivation。

正文使用自然语言和有意义的标题，不需要来源、操作时间、记录状态或 YAML frontmatter。人生中的年份与阶段可照常记录。没有内容的模块留空即可，不写占位问卷。

含义不确定时在对话中澄清或暂不保存，不创建待分类档案。用户不愿提供某领域时尊重选择，不设置页面状态，也不把跳过写成人格特征。

# NOME display font

Noto Sans SC Medium (500), a 9 KB title-only subset served locally.

Source: [Google Fonts Noto Sans SC](https://fonts.google.com/noto/specimen/Noto+Sans+SC). Retrieved 2026-10-18 through the official Google Fonts CSS API with a `text` subset for `nome.` and the six Chinese domain names. Binary downloaded from fonts.gstatic.com without further modification.

License: [SIL Open Font License 1.1](OFL.txt), retrieved from the google/fonts repository via jsDelivr. Font copyright is retained in that file.

Only the central identity and fixed domain headings use this face. User-authored content uses the system Chinese text stack. Pages never request Google Fonts or any external resource at runtime.

# NOME local fonts

## Chinese headings

Noto Sans SC Medium (500), a title-only subset served locally.

Source: [Google Fonts Noto Sans SC](https://fonts.google.com/noto/specimen/Noto+Sans+SC). Updated 2026-10-19 through the official Google Fonts CSS API with a `text` subset for `nome.` and the six role-profile category names (身份与处境、动机与价值、特质与偏好、能力与经验、关系与连接、经历与变化) and the error heading. Binary downloaded from fonts.gstatic.com without further modification.

License: [SIL Open Font License 1.1](OFL.txt), retrieved from the google/fonts repository via jsDelivr. Font copyright is retained in that file.

Only fixed Chinese domain headings use this face. User-authored content uses the system Chinese text stack. Pages never request Google Fonts or any external resource at runtime.

## NOME wordmark

Michroma Regular (400), designed by Vernon Adams / The Michroma Project Authors.
The distinctive wide, rounded-square display letterforms are used only for the
centred uppercase NOME wordmark; small planet labels retain a readable sans-serif.

Original, unmodified font: michroma-regular.ttf (64,344 bytes).
Source: [google/fonts Michroma](https://github.com/google/fonts/tree/main/ofl/michroma).
Downloaded from the official repository on 2026-10-20.
License and copyright: [SIL Open Font License 1.1](Michroma-OFL.txt).

The font is preloaded and served locally. Runtime pages do not contact a font CDN.

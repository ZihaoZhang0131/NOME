# NOME 个人星图

Mode: Operate。用户已确认方向，直接以代码实现当前看板；不记录未来项目的默认制作流程。

## Direction contract

THESIS: 六个生活领域围绕同一个人，星图同时是领域筛选器。档案内容随选择呈现，图形不是评分或完成度。

OWN-WORLD: 本地银河背景、温白文字、六颗具有不同地貌、云带的行星。六颗行星沿同一条倾斜轨道公转；记录用清晰的分栏和横线组织。

STORY: 探索星图 → 点击领域节点 → 阅读完整 Markdown 与章节 → 返回星图。仅展示正式正文，不呈现记录状态、来源或操作时间。

FIRST VIEWPORT: 首页展示全屏银河星图与位于完整轨道上方、水平居中的 NOME 项目字标；使用本地 Michroma 展示字体。六个英文单词直接位于星球表面，保留轻量暂停按钮；不新增描述、卡片、导航栏和页脚。悬停或键盘聚焦领域时行星本体平滑放大 18%（180ms），不新增外圈。点击后镜头连续接近选中行星，放大到桌面左侧，右侧展开阅读；手机上方展示近景、下方阅读。支持返回星图、浏览器前后导航与领域深链接。减少动态效果设置下静态呈现。

FORM: 用户明确指定的个人星图；无需随机选择视觉方向。引擎不可用，seed: none (unavailable)。领域节点为原生按钮，阅读视图保留六领域切换与多文档章节导航。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Orbital refinement

最新方向：移除太阳及暖色光晕，六领域分别使用水星、金星、地球、火星、木星、土星材质；本地贴图按球面投影，地球合成云层，土星外部星环已移除。行星大小表达视觉身份，不随资料状态改变。

六颗行星共享修长椭圆轨道（半长轴 270、离心率 0.46、倾角 62°、画面旋角 -18°），几何中心居中，轨道与球体共用正交投影。15 秒一圈，比上一版 30 秒周期再快一倍，按开普勒方程实现近端快、远端慢，速度比约 2.7。六颗行星覆盖 180° 平近点角，内部相隔 36°、首尾留空 180°；初始可见弧长覆盖 1/2，随变速自然疏密变化。名称位于球体正面中央，保持正向可读，随球体运动；移除外置标签及其避让逻辑。悬停与键盘聚焦时暂停。

暂停按钮移到舞台右下角。保留小幅鼠标视差、950ms 推进、750ms 拉远、快速返回和详情导航。阅读、后台和离屏停止运动，系统减少动态效果时静态呈现。六颗行星保留 180–240 秒周期的球面自转，使用本地贴图与 WebGL，GPU 不可用时以限帧 Canvas 降级。无新增运行时依赖。

背景改为本地 Solar System Scope 银河星空纹理，保留出处和 CC BY 4.0 授权。移除人工 SVG 散点，在阅读区加深背景遮罩。星球直径 60（半径增大 50%），圆形点击区域至少 44px，保留每颗星球的独立点击入口。

球面名称显示为 Identity、Values、Traits、Skills、Bonds、Growth；中文完整分类仍用于无障碍名称、悬停提示和详情。放大后密集段允许少量前后交叠，但确保每颗星球的中心与独立点击入口可见。

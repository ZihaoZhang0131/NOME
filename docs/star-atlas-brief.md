# NOME 个人星图

Mode: Operate。用户已确认方向，直接以代码实现当前看板；不记录未来项目的默认制作流程。

## Direction contract

THESIS: 六个生活领域围绕同一个人，星图同时是领域筛选器。档案内容随选择呈现，图形不是评分或完成度。

OWN-WORLD: 深墨绿背景、温白文字、太阳与六颗具有不同地貌、云带、星环的行星。六颗行星沿同一条倾斜轨道公转；记录用清晰的分栏和横线组织。

STORY: 探索星图 → 点击领域节点 → 阅读该领域记录及来源 → 返回星图。未知、待核实、草稿和主动留白在阅读视图中用文字区分。

FIRST VIEWPORT: 首页仅展示全屏星图，保留六个领域短标签与中心 NOME，不出现标题、描述、卡片、导航栏和页脚。悬停或键盘聚焦领域时节点外环亮起，中心显示该领域。点击后镜头连续接近选中行星，放大到桌面左侧，右侧展开阅读；手机上方展示近景、下方阅读。支持返回星图、浏览器前后导航与领域深链接。减少动态效果设置下静态呈现。

FORM: 用户明确指定的个人星图；无需随机选择视觉方向。引擎不可用，seed: none (unavailable)。领域节点为原生按钮，阅读视图保留六领域切换与来源折叠。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Orbital refinement

最新方向：中心太阳，六领域分别使用水星、金星、地球、火星、木星、土星材质；本地贴图按球面投影，地球合成云层，土星外部星环已移除。行星大小表达视觉身份，不随资料状态改变。

六颗行星共享同一三维轨道（半径 220、倾角 67°、画面旋角 -18°），统一以 120 秒为公转周期，六颗行星固定相隔 60°；共享投影用于轨道与运动坐标。透视缩放和按深度排序带来前后穿越，太阳遮挡背后的行星。悬停与键盘聚焦时暂停，键盘焦点临时提升层级，保证被遮挡的领域也能访问。

鼠标视差、中心暂停控制继续保留。镜头 950ms 推进、750ms 拉远，保留同一行星与轨道时刻；快速返回从当前插值帧反转，领域间切换重新定位镜头。阅读、后台和离屏停止公转；系统减少动态效果时静态呈现、直接导航。球面像素仅在加载时生成一次，动画每帧只计算六个轨道坐标和光照方向。无新增运行时依赖。

# 个人星图 / Personal atlas

保留全屏星图方向，0.2 将详情简化为完整 Markdown 阅读。

- 首页仅保留星图、六类全名标签和中心 NOME。没有标题、说明、卡片、顶部导航和页脚。
- 深墨绿背景中，以一条共享倾斜轨道、太阳与六颗太阳系行星和星点构成可探索的领域入口。图形大小不表示能力、人格或完成度。
- 悬停或键盘聚焦节点时，行星本体平滑放大 18%（180ms），不新增外圈、中心切换领域名称。点击后同一行星持续放大并停靠桌面左侧，右侧阅读；手机上方行星、下方阅读；返回入口和浏览器前后导航均可回到星图。
- 阅读页直接展示完整 Markdown，支持章节、列表、表格、代码和文内链接。移除来源、操作时间、条目状态和统计。空模块只显示一句提示；演示详情仍标记“虚构示例”。
- 六颗行星保持 60° 间隔，以相同速度缓慢公转，鼠标移动带来小幅视差，节点文字保持稳定。点击节点以 950ms 镜头推进进入近景，返回以 750ms 拉远到原星系。中心字标可暂停动态，阅读、离屏和后台自动暂停；响应系统减少动态效果偏好。
- 轨道由 SVG 绘制，行星使用本地太阳系贴图进行 Canvas 球面投影；运行时不访问外部资源，不新增依赖。页面只读，不保存浏览偏好，不写个人档案。

方向约束见 [star-atlas-brief.md](star-atlas-brief.md)。截图为开发验证资料，不进入分发包。

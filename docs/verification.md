# 验证说明

## 自动化检查

需要 Node.js 22+，无需安装 npm 依赖。

```sh
npm run check
npm test
npm run pack
```

- `check`：JavaScript 语法、JSON、文档相对链接、Skill 元数据及零运行时依赖。
- `test`：档案读写与并发保护、输入校验、迁移兼容、安装升级卸载、来源发现、本机只读接口、Markdown 阅读、轨道运动及镜头构图。
- `pack`：生成 `dist/nome-skill-0.2.0.tgz`，检查分发文件范围、个人机器路径和私有运行文件。

当前检查结果：45 项自动化测试通过，53 个文件检查通过，分发包包含 40 个文件，未包含个人档案。

测试使用临时目录与虚构资料，不读取真实个人档案。对话行为的人工验收场景见 [scenarios.md](../evals/scenarios.md)。

## 界面检查

当前首页预览见 [preview.png](preview.png)，使用独立的虚构演示数据。

已检查桌面 1280×720、窄屏 390×650 与短屏 900×320 的布局：标题位于完整轨道上方，悬停放大与视差仍保有间距，无横向溢出；短屏完整容纳标题和星图。窄屏与短屏通过桌面浏览器的本地演示 iframe 检查，未使用实体手机。

桌面 Skills 和窄屏 Traits 的详情进入、中文标题焦点、返回与字标恢复已检查。六颗行星的英文名称位于球面；紫色全天紫外星图背景与行星材质均从本地加载。桌面与窄屏背景满铺，未露出原图的椭圆边框，正文区域的暗色遮罩保持可读。

自动化检查不证明所有浏览器、GPU 或 Agent 对话行为完全一致。减少动态效果与 Canvas 降级路径应在目标设备发布验收时复核。

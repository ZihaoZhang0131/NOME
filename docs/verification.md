# NOME v0.1 验证记录

验证环境：macOS，本地 Node.js v24.14.0。使用虚构资料和系统临时目录，不导入真实个人记忆。

## 自动化与打包

- `npm test`：24 项通过，0 失败、0 跳过。覆盖隔离双宿主安装、重复安装、升级、卸载、未知目录保护、来源缺失/不可读/过大、初始化确认、精确去重、问答草稿转正式、并发和版本冲突、只读不变、撤销与彻底删除、损坏数据保留、HTTP 访问边界和端口回退。
- `npm run check`：22 个文件通过 JavaScript 语法、JSON、相对文档链接及 Skill 入口检查；运行时依赖为 0。
- skill-creator 的 `quick_validate.py`：通过。系统 Python 缺少 PyYAML，使用临时 uv 环境运行验证器；没有为 NOME 添加 Python 或其他运行时依赖。
- `npm run pack`：生成 `dist/nome-skill-0.1.0.tgz`，19 个发布文件。打包白名单检查排除了测试、预览截图、实际档案、安装标记、临时文件和开发者本机绝对路径。
- 实际对生成的 tgz 执行了隔离的 `npm install --global --prefix …`，验证全局 bin 能运行、两种宿主均能安装、复制的 Skill CLI 在独立目录可读取空档案，随后清理临时安装。未安装进真实用户的宿主目录。

## 浏览器

- 使用应用内浏览器检查 1280×960 桌面与 390×844 手机视口；两种宽度的根文档 scrollWidth 均等于 clientWidth，无页面横向溢出。手机领域导航可横向滚动，内容为单列；测试后恢复浏览器默认尺寸。
- 演示数据明确标记“虚构示例”；来源展开能区分记忆导入与“尚未确认”。领域筛选正常，点击刷新后保留所选领域。
- 独立临时数据目录的真实页面显示 0/6，且页面访问没有创建档案文件。用 CLI 保存一条虚构偏好后刷新，显示 1/6、档案版本 1 和新内容。
- 验证记录包含字面 `<script>` 字符串，页面将其显示为文本，无脚本执行。
- 桌面与手机截图保存为本目录下的 preview-desktop.png、preview-mobile.png；截图仅含虚构资料，不进入分发包。验证结束后关闭测试服务。

## 宿主行为边界

- Codex 与 Claude Code 的安装位置以及每个安装副本里的 CLI 均由隔离测试验证；这不等于在新宿主会话里验证了模型行为。
- SKILL.md 触发描述、分模式参考文件与问答路线包含真实验收场景，详见 [宿主验收场景](../evals/scenarios.md)。
- 本次尚未在独立 Codex／Claude Code 会话运行模型行为验收；隐式触发、动态追问质量与拒绝未授权写入仍需按场景进行宿主实测。程序层的授权、确认、版本和写入边界由自动化测试单独覆盖。
- Linux 与 Windows 尚未实机验证；不将使用可移植 API 等同于这些平台已通过。
